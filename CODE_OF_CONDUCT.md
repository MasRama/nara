# Code of Conduct

## Our standard

Nara is an open-source project. Participation should be welcoming, technical,
and respectful.

Examples of expected behavior include:

- discussing ideas and code on their merits;
- giving specific, actionable feedback;
- respecting different levels of experience and different technical opinions;
- acknowledging mistakes and correcting them;
- keeping disagreement focused on the work rather than the person.

Harassment, threats, discriminatory language, sustained personal attacks,
doxxing, sexualized attention, and deliberate disruption are not acceptable.

## Scope

This standard applies in Nara's repository, issues, pull requests, discussions,
and other project spaces where someone is participating as a member of the Nara
community.

## Enforcement

Maintainers may edit or remove comments, close conversations, reject
contributions, or restrict participation when behavior violates this standard.
Enforcement should be proportionate, consistent, and focused on keeping project
spaces safe and productive.

For conduct concerns that can be discussed publicly, open an issue with only the
information appropriate for a public repository. For a sensitive concern,
contact the repository maintainer privately through GitHub rather than posting
private or identifying information in an issue.

Security vulnerabilities are handled separately through
[`SECURITY.md`](./SECURITY.md).
